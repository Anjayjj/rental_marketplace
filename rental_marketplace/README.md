# 🚀 Rental Marketplace System
Aplikasi penyewaan barang Peer-to-Peer (P2P) berbasis PHP 8 Native & MVC Architecture.

## 🛠 Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, JS (ES6), Bootstrap 5, AJAX, Chart.js
- **Backend:** PHP 8 (Native MVC), PDO
- **Database:** MySQL 8 / MariaDB

## ⚙️ Cara Instalasi
1. Clone repositori atau ekstrak file ke folder `htdocs` (XAMPP) atau `www` (Laragon).
2. Buat database baru di phpMyAdmin dengan nama `rental_marketplace`.
3. Import file `database.sql` ke dalam database tersebut.
4. Buka folder `app/config/config.php` dan sesuaikan pengaturan koneksi database jika diperlukan.
5. Akses aplikasi melalui browser: `http://localhost/rental-marketplace/public`
